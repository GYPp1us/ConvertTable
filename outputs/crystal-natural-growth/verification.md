# 自然晶簇、黑色包边与石材对比 · 2026-09-28

四面晶体采用独立的非对称生长构图，以不同高度、宽度的晶柱和分离小簇打散倒三角。四条棱柱新增两面环抱的黑石包边，上下所有角套统一为黑石。白色横边、灰色矿岩、黑色护角分别以原版方解石 / 平滑玄武岩 / 深板岩的原生像素色块加强纹理对比。

- 191 个可编辑 cuboid、14 个命名组、2323 个连通整数体素，边界 16×16×16，无重叠和悬浮。
- 16 套当前材质、648 个运行时面；完整资源检查通过 50 套材质、6420 个面。
- 保存的 Blender 模型重新打开检查，并完成正面、侧面、斜视与暗光渲染。
- 白色方解石亮度标准差由 2.51 增至 20.63，黑石由 2.51 增至 17.51，灰色基底由 4.02 增至 21.20。
- 所有角套与棱柱包边均已验证为黑石材质。专用 `geode_*` ID 保留了触媒底座原有的 36 张共享贴图，其他方块模型哈希与修改前一致。
- 离线 Gradle 9.6.0 `build` 及隔离 Vulkan `runClientGameTest` 通过；日志：`build-and-game-test.log`。
- JAR 中 74 个相关资源文件逐字节匹配源文件，SHA-256 与检查结果见 `package-check.json`。
