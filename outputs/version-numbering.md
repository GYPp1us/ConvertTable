# 版本编号约定

| 原编号 | 当前编号 |
| --- | --- |
| v1.5.1 | v0.1.0 |
| v1.5.2 | v0.1.1 |
| 此前本地构建 v0.0.1 | v0.2.0 |

当前模组版本以 `gradle.properties` 为准。今后的发布沿用此编号体系；配方表、README、发布标题、文件名与包内元数据须使用同一版本。

历史源码保留原提交，只增补修改版本字段的提交供新标签指向。历史安装包仅修改 `fabric.mod.json` 的版本，源码包内容保持原样，游戏实现不变。旧默认配方迁移继续识别原 v1.5.2（现 v0.1.1）的固定数据指纹，不受重编号影响。

原发布元数据、附件和校验和已保存在本地 `build/version-renumber/original/`；新编号包在 `build/version-renumber/renumbered/`。历史远端标签和附件已按用户确认替换，保留原发布日期。发布工作流保持启用；已有发布重复执行时保留说明与已验证附件，手动执行时检出指定标签。
