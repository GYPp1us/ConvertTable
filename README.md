<h1 align="center">ConvertTable</h1>

<p align="center"><b>中文</b> · <a href="README.en.md">English</a></p>

把建筑材料换成需要的样式，或用紫水晶晶脉持续生产方块。

当前版本 **v0.3.1**，适用于 **Minecraft Java 26.3 / Fabric**。五种方块都可以在工作台合成，也可以在创造模式的**功能方块**分类找到。

## 安装

从 [Releases](https://github.com/GYPp1us/ConvertTable/releases/latest) 下载适用于 26.3 的模组 JAR，与 [Fabric API](https://modrinth.com/mod/fabric-api) 一起放入 `mods`。需要 Fabric Loader 0.19.5 或更高、Java 25。联机时客户端和服务器都要安装同一版本；版本不同或未安装本模组的客户端会在进入世界前被拒绝。更新时移走旧版，只保留一个启用的模组文件。不要安装带 `-sources` 的文件。

## 黑金转换台：随机换材料

1. 右击台子，把材料放入**投入槽**，把金粒放入**燃料槽**。
2. 点击**开始转换**，领取输出槽里的产物。
3. 想持续处理，就开启**连续**；条件满足时台子会自动开始下一批，关闭界面后仍会继续。

黑金台没有目标选择器。例如，投入橡木木板，会随机得到同组的另一种木板；连接棒也可让它从指定容器取料、把产物送到指定容器。黑金的普通转换数量比例是 **1:1**，不会抽到输入本身。

默认每批消耗 **1 个金粒**。每批上限由配方决定，不足一批也收一次费用。产物交付时才扣材料和金粒；计时到达完成而输出堵塞时，进度会停在完成状态等待空间，腾出空间后即可收取结果。

## 末地转换台：指定目标

1. 把材料放入**投入槽**，把**紫颂果**放入燃料槽。
2. 在右侧找到并点击目标产物。
3. 点击**开始转换**，或开启**连续**。开启连续后，投入槽或连接输入有可处理材料时会自动开始下一批，无需逐批点击。

末地台可处理黑金台的全部普通转换组，并提供更多转换组。普通转换仍是 **1:1**。默认一颗紫颂果补充 **16 点相位**，每批消耗 **1 点**，只有成功转换才扣费。幽匿台处理这些组时，每批消耗 **3 个可用灵魂**。

### 连接容器和处理潜影盒

末地台和幽匿台支持三种输入模式：

| 模式 | 如何使用 | 产物去哪 |
| :--- | :--- | :--- |
| **投入槽** | 直接放入材料，再选择目标 | 台子的输出槽；若已连输出容器则送入该容器 |
| **连接容器** | 用连接棒分别连接输入容器和输出容器，再选择目标 | 取输入容器内的材料并送入输出容器 |
| **潜影盒内容** | 将一个潜影盒放入投入槽，再选择目标 | 替换潜影盒内的材料；处理后手动取回盒子 |

连接容器不会自动扫描附近方块。使用连接棒连接一座转换台和一个容器；按容器输入角色左键连接，按输出角色右键连接，先点台或先点容器均可。输入连接显示绿色，输出连接显示橙色。连接需在各轴距离合计 **16 格**内，每台最多 **8 个输入/输出连接合计**；不能把同一个容器同时设为输入和输出。点击容器的面决定漏斗侧面规则，双箱仍算一个容器。

重复连接同一角色可移除连接；手持连接棒潜行点击台子可清空对应角色。清空全部输入连接后，转换台自动回到投入槽模式。连接棒由一根木棍无序合成。触媒基座只支持输出连接。

连接容器和潜影盒模式可切换匹配方式：

- **精确匹配**：连接容器模式把投入槽里的物品当作样本，样本不消耗。潜影盒模式会锁定第一种成功转换的材料；重新选目标、切换输入模式或匹配方式可重置。
- **同组匹配**：处理容器里所有能按配方转换成所选目标的材料。

潜影盒会保留名称和未处理的内容，不会继续打开盒中盒。输入容器或输出容器无法访问时不会扣除材料或费用；普通转换可按剩余空间减少本批数量，成功时仍按一次批次扣费。转换台按固定时长处理：黑金 **4 秒**、末地 **2 秒**、幽匿 **1 秒**；界面显示进度动画。计时完成时若输出堵塞，进度会停在完成状态等待空间，腾出空间后即可收取结果。

## 幽匿转换台：收集可用灵魂，完成转换

普通转换每批消耗 **3 个可用灵魂**，不消耗相位。进阶配方按配方消耗可用灵魂；放入主材料和指定的**催化材料**后选择产物即可执行。催化材料会消耗；空桶等副产物进入**返还槽**。有些配方不需要催化材料或返还物；带候选池的配方会随机等概率产出其中一种。

进阶转换消耗台内显示的**可用灵魂**，不会扣相位或玩家经验。标为**仅手动**的配方只能用投入槽点击转换，不能连续执行，也不能处理容器内容。升级旧世界时幽匿台燃料槽里的旧相位燃料会掉落到地面。

### 生命塑形与种子抽卡

钓鱼可获得四种塑形材料，名称保留英文，每种都有一行文案。将材料放入幽匿台投入槽，按配方加入植物、食物或矿物等催化材料，再选择刷怪蛋并手动转换。塑形材料和催化材料都会消耗，不能连续塑形；不需要先取得目标生物自身的掉落物。

| 钓鱼材料 | 主要用途 | 文案 |
| :--- | :--- | :--- |
| Boughbound Reverie | 陆生、飞行与自然生命；远古种子抽卡 | 枝节蔓生叶繁茂，百兽长栖息 |
| Stillwater Palimpsest | 水生生命 | 雪泥洗濯发与肤，明镜无风波 |
| Unbroken Cognizance | 村民、流浪商人 | 一日发蒙生灵智，代代相连结 |
| The Unwrought Facet | 灵异、亡灵与构造生命 | 泥土血肉皆不容，百相映其中 |

塑形覆盖当前原版友善生物，具体材料、数量和灵魂费用见界面、JEI 或配方 Excel。

普通作物抽卡每次投入 **16 粒小麦种子 + 4 份骨粉 + 24 个可用灵魂**，等概率获得一件小麦种子、南瓜种子、西瓜种子、甜菜种子、胡萝卜或马铃薯，可开启连续。远古作物抽卡投入 **32 粒小麦种子 + 1 件 Boughbound Reverie + 96 个可用灵魂**，等概率获得火把花种子或瓶子草荚，只能手动。

四种塑形材料来自通常钓到鱼的那一类收获；紫水晶碎片也可作为宝藏钓到，每次 1–3 片，需要原版开放水域条件。其他模组或服务器可能调整钓鱼结果。

### 怎样补充可用灵魂

用幽匿方块或相连的幽匿脉络把台子与死亡区域接通。让生物站在**顶面无遮挡、与台连通的幽匿方块**上死亡。

- 合格生物死亡时，按该生物应掉落的经验值换算可用灵魂：**1 点经验 = 32 个可用灵魂**，每台最多储存 **4096 个**。默认不要求玩家亲手击杀；本来不会掉经验的生物（包括不掉经验的幼年动物）提供 **0 个**。
- 玩家、盔甲架和悬空死亡不会充能。死亡区域必须位于台子的幽匿网络范围内，按各方向距离合计最多 **16 格**，网络最多连接 **1024 格幽匿节点**，只统计已加载区域。
- 经验球、战利品与幽匿催发体的原版行为不受影响。服务器若配置为要求玩家击杀，则只记录玩家造成的合格死亡。
- 多张台共用幽匿网络时，一次死亡只归属于连通路径最近的一张台，不会重复增加。
- 断开地面、退出存档或卸载区块会保留已存灵魂。拆掉台子会掉落槽内物品，但可用灵魂不会跟着方块带走。

幽匿台界面的**范围**页显示网络的 X–Z 俯视图：每格代表一个水平位置，不同高度会合并显示。亮色格是可收集灵魂的幽匿表面，暗色格是其他连通节点，黄色标记台子；未加载区块或扫描超限时会提示范围不完整。

## 母岩增殖台与触媒基座：持续生产

### 1. 搭建晶脉

用**紫水晶方块**将**紫水晶母岩**与母岩增殖台面对面连起来，给母岩留出晶芽生长的空位。晶芽导出的生长因子会供给整条晶脉。

晶脉没有固定距离、节点数或母岩数量上限，只处理已加载的区域。多座母岩增殖台可以接入同一晶脉，共用晶芽提供的生长因子；多放台子不会凭空增加产量。未加载的部分恢复加载后才会参与工作。

### 2. 接上基座，放入触媒和源本

将**触媒基座**紧贴增殖台、紫水晶方块或母岩放置。右击基座，在左侧两个槽放入 **1 件触媒 + 1 件目标物品作为源本**，选择对应目标，再点击**开始增殖**。例如生产橡木原木，需要橡树树苗作触媒、橡木原木作源本。缺少源本或放错源本时，界面会提示补齐，不能开始。需要停机时点击**暂停增殖**。

例如，**橡树树苗**可以作为橡木原木、橡树树苗或橡树树叶的触媒；红树使用红树胎生苗，菌柄和下界植物使用对应菌类，竹子使用竹子作触媒。增殖目录覆盖基础原木、树苗、树叶、沙土石料、常见花草等原版低阶材料；去皮原木、木板、砂岩、玻璃和其他加工品不作为产物。树苗、菌类等自然触媒，以及紫水晶碎片、回响碎片、海洋之心和末影珍珠等魔法触媒都不会消耗，也不需要工具。

触媒和源本**都不会消耗**，必须一直留在各自槽中。重命名、附魔等带有额外数据的物品不能作触媒或源本。有效且开启的基座会尽量平分同一条晶脉的生长因子，暂停或输出满的基座不会占用份额。界面显示当前产速和下一件进度，慢速生产也会逐步累积。暂停保留部分进度；更换触媒、源本或目标会清空当前部分进度。已经产出的物品会保留。

### 3. 收取产物

产物先存入基座的 **9 个输出槽**，并送入连接棒指定的输出容器。查看基座界面里的连接状态，确认箱子能接收所选产物。没有连接输出容器或容器已满时，产物会留在输出槽。

### 4. 提高产量

- 每个未成熟晶芽的抽取上限默认为 **1/64 生长因子/秒**。
- 将**方解石**贴在母岩旁，可将该母岩未成熟晶芽的抽取上限提高到 **2/64 因子/秒**，不改变内涵量；贴在连通紫水晶导体旁，则影响整条晶脉。
- **平滑玄武岩**让每个未成熟晶芽的内涵量增加 **1/64**，不提高每秒抽取上限。母岩旁作用于该母岩，连通紫水晶导体旁作用于整条晶脉；同种增益不叠加。
- 成熟晶簇不再导出生长因子。晶脉可用且有有效基座正在增殖时，成熟晶簇会重新变为小晶芽。

手持基座、方解石或平滑玄武岩对准可用晶脉位置时，准星旁会出现放置提示。

小晶芽、中晶芽、大晶芽和成熟晶簇的自然内涵量分别为 **16/64、8/64、4/64、1/64** 生长因子。内涵量表示晶芽所含的生长因子；每秒抽取上限表示晶脉每秒最多能从它抽出多少。未成熟晶芽的抽取上限为 **1/64 因子/秒**，成熟晶簇为 0。

晶脉总产速没有固定上限，可通过增加有效母岩和晶芽扩建。母岩界面可查看各阶段晶芽数量；悬停供给或内涵量可查看当前来源与计算，右上方两种增益方块说明各自作用和摆法。

### 用连接棒设定输入和输出

连接棒由一根木棍无序合成。手持连接棒，依次左键点击转换台和容器建立输入，依次右键点击台子和容器建立输出；端点点击顺序不限。输入连接为绿色，输出连接为橙色。重复同角色连接会移除，潜行点击转换台可清空该角色；清空输入后会回到投入槽模式。连接最多各轴距离合计 **16 格**，每台输入和输出共 **8 个容器**。点击容器的面遵循该面的漏斗收取/放入规则；触媒基座只支持输出连接。

转换台可仅连输出，让投入槽产物直接进入目标箱子；也可连输入和输出组成容器处理链。黑金台从连接输入随机转换，不需要选择目标。所有链接都是明确设置的端点，不会自动扫描邻近容器。

## 漏斗自动化

| 方块 | 投入 | 取出 |
| :--- | :--- | :--- |
| 转换台 | 顶部投入材料；侧面投入燃料或幽匿催化材料 | 底部取出产物和返还物 |
| 触媒基座 | 顶部投入一个有效触媒和一个源本 | 侧面或底部取出产物；连接棒指定输出容器 |

转换台自动执行前记得开启**连续**；开启后，投入槽或连接输入中的材料和费用足够时会自动开始下一批，不必再次点击。若输出堵塞，进度仍会走到完成并停在那里等待出料，交付产物时才扣材料和费用；普通转换会按可用输出空间减少本批数量。触媒基座需要点击**开始增殖**。幽匿台侧面只接收催化材料，请只输送配方需要的材料，避免堵槽。

## 查配方与排查问题

完整默认配方见 [配方 Excel](outputs/01a0f354-50a1-7850-9a3e-c4f75b90728b/ConvertTable配方.xlsx)：**107 个普通转换组、118 条幽匿进阶配方、105 条触媒增殖配方（19 种触媒）**，以及六条工作台合成配方。总览页也列出钓鱼材料。

部分农夫乐事转换组和种子抽卡进阶配方需要安装**农夫乐事**后才能使用；Excel 仍会列出这些可选模组配方。

可选安装适用于 26.3 的 **JEI 或 REI** 来查转换配方和用途；JEI 还会显示母岩增殖台与触媒基座的增殖配方。触媒增殖目标也可在基座界面或 Excel 中查看。联机服务器可能调整转换配方，实际材料和费用以游戏内为准。

**升级后找不到新配方**：确认客户端和服务器只启用同一新版模组。未改过的 0.1.1（原 1.5.2）、0.2.0 和 0.3.0 默认配方会在升级时备份并补齐；定制过的配方会保留，需要服务器管理员补入新增配方后重启。联机后的增殖目录以服务器为准。JEI 增殖配方可在触媒、源本或台子物品上按 **U**、在产物上按 **R** 查看。

**转换没反应**：查看界面提示，检查目标、材料、燃料、催化材料、可用灵魂，以及输出和返还槽空间。仅手动配方请使用投入槽。

**基座不产出**：检查是否已开启增殖、触媒和源本是否有效且对应所选目标、晶脉是否接通、母岩上是否有晶芽且区块已加载。缓慢增殖时观察下一件进度是否增长；最后检查输出槽和连接棒指定的输出容器是否已满。旧基座升级后需要先补入源本再开启。

游戏内进度页提供转换成就与紫水晶引导。三种转换台的成就直接显示；晶洞成就跟随紫水晶引导，成功增殖后揭晓。合成成功即可达成，不必等待容器出料。
