# v0.3.2：每小时 100k 生长因子的规模

口径：100k 指每小时 100000 个生长因子，不是物品数。按 1/1000 换算，方解石按不同物理方块叠加；只统计已加载、连接有效的晶芽与矿物。当前每件增殖产物的费用仍为 1–4 个完整生长因子。

## 已在游戏实际验证的 418 方块方案

| 组成 | 数量 |
| --- | ---: |
| 紫水晶母岩 | 41 |
| 未成熟晶芽 | 165 |
| 紫水晶块导体 | 42 |
| 方解石 | 168 |
| 母岩增殖台 | 1 |
| 触媒基座 | 1 |
| 合计 | 418 |

把增殖台设为中心；一侧连 41 块母岩成直线，另一侧连 42 块紫水晶块成直线，触媒基座接在紫水晶块末端。每块母岩上下、前后各留一个晶芽面，最末母岩再留外端面，共 `41×4+1=165` 个晶芽。每块紫水晶块上下、前后各贴一块方解石，共 `42×4=168` 块；基座占用末端面。方解石必须贴导体，才能对全部晶芽生效。

这条直线方案外包尺寸为 **86×3×3 格**；内部有空位。418 是实际参与方块数，不含地基、出料容器或装饰。折叠摆放可以缩短外包尺寸，但必须重新核对被连接占用的晶芽面、矿物面与重复矿物；不能直接沿用这条直线的数量。

每个晶芽抽取上限为 `(1+168)/1000 = 0.169` 因子/秒。因此：

`165 × 169 / 1000 × 3600 = 100386 因子/小时`

`GrowthStackGameTest` 实际搭建全部 418 块，核对 41 母岩、42 导体、165 晶芽和 27885 微因子/秒；再通过实际增殖生产和存档验证：一秒产出 13 根原木、保留 1.885 因子进度，两秒累计 27 根、保留 1.770 因子。成熟晶簇自动重置后仍恢复同一供给。测试不以真实时间空跑一小时，小时值从实际每秒预算换算。

## 生长速度与持续输出

满负荷抽取、无平滑玄武岩时，自然生长达到原版 **15%** 的保底。增殖按有效晶芽每秒抽取，并不等待晶芽长成后才能供给；有有效基座工作时成熟晶簇会自动变回小晶芽。平滑玄武岩增加内涵量、减轻生长减速，不直接提高因子每秒供给。

维持该小时效率须保持整条晶脉加载、基座开启、触媒与源本有效，以及出料畅通。未长出、被打掉、未加载的晶芽不计供给；堵塞或暂停时没有分配的供给不存入仓库。

原木费用为 2 因子/件，满效率约 **50193 根/小时**。同网多基座共享供给，不会乘倍增加整网因子；混合费用的配方产出需分别按分配到的因子除以费用计算。

## 规模参考与平衡含义

以下仍采用两条直线及四面挂载，所有方解石对整网生效：母岩 M、导体 C，对应 `4M+1` 晶芽和 `4C` 方解石；总数 `5(M+C)+3`，小时效率 `3.6×(4M+1)×(4C+1)`。

| 母岩 | 导体 | 实际方块总数 | 因子/小时 |
| ---: | ---: | ---: | ---: |
| 41 | 41 | 413 | 98010 |
| 41 | 42 | 418 | 100386 |
| 50 | 50 | 503 | 145443 |
| 100 | 99 | 998 | 573109.2 |

418 是此类直线方案达到 100k 的门槛；没有穷举所有三维连接方式，不能声称它是全局绝对最小。整网增益叠加后，晶芽与方解石同时增加会形成乘积收益；1/1000 缩小单份供给，并未让大规模供给线性增长。
