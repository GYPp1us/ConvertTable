# v0.2.0 最终验收

日期：2026-10-02（Asia/Shanghai）。Minecraft 26.3 / Fabric Loader 0.19.5 / Java 25。按用户要求将当前版本编号改为 v0.2.0（此前本地编号 v0.0.1）。本轮改用树苗、菌类和自然/魔法材料作增殖触媒；105 条配方的稳定 ID、产物与生长因子费用逐条保持不变。保留此前计时、连续处理、死亡经验换算及未修改的 1.5.2 默认配置迁移。历史环境证据见 `../recipe-audit-2026-10-02/audit.md`。

## 已完成的行为

- 三种转换台和触媒基座使用原版按钮处理目标点击；真实鼠标验证目标、翻页、模式和开始/暂停操作。无触媒、无配方物品和带自定义组件物品不会使菜单崩溃。
- 幽匿范围显示为 X–Z 俯视图，合并同一水平位置的网络高度；1089 个格子和有符号短整数同步边界已覆盖。
- 连接棒由一个木棍无序合成。连续左键配对输入、连续右键配对输出，两种端点顺序均可；绿/橙图标及粒子区分角色。每台最多 8 个端点、曼哈顿范围 16，支持双箱去重、角色冲突、重复移除、潜行清空和存档持久化。触媒基座只连输出。
- 三种转换台都支持显式连接容器；取料与出料遵循点击容器的面。输出堵塞时不扣主材、催化材料、金粒或可用灵魂；部分可用空间只缩小普通批次。
- 黑金、末地、幽匿分别计时 80/40/20 个实际服务器刻（20 TPS 下为 4/2/1 秒），完成交付时才扣费。UI 显示真实进度与剩余秒数，工作中禁止重复启动；输出堵塞保留 100% 进度，腾出空间后完成出料。改变主材、目标、模式、样本或催化材料会取消旧工作，单纯加料不会重置或扩大已开始的批次。
- 开启连续后，投入槽、连接输入容器与潜影盒在资源足够时自动开工；补料、补灵魂或解除出料堵塞后自动继续。幽匿普通每批默认消耗 1 个可用灵魂，进阶按原配方消耗，均不扣相位。旧 JSON 缺少普通灵魂费字段时仍按 1 读取；兼容 JSON/NBT 标识保留，玩家界面统一显示可用灵魂和当前费用。
- 幽匿普通与进阶转换均为 0 相位费用；旧配置非零兼容字段不扣相位，旧燃料槽物品掉落返还。
- 1.5.2 完整未修改默认配置按规范化指纹识别，先备份原始字节，再原子替换为新默认。修改费用/设置、禁用/删除/编辑条目的定制配置不变。已直接用旧配置启动隔离世界，确认自动加载 107 组普通转换/83 条进阶。
- 合格死亡按原版死亡经验奖励换算：1 点经验提供 32 个可用灵魂，零经验及不掉经验的幼年动物提供 0；默认自动击杀也可充能。复用原版首次计算的奖励，避免装备、附魔与随机经验重复计算；原版经验球、战利品及幽匿催发体蔓延保持正常。每台默认上限 4096，使用长整数乘法避免极高经验溢出，存档保留当前灵魂数。
- 玩家用语统一为生长因子。晶脉按基座剩余需求尽量均分因子，余数轮换，并保存分配位置和基座余因子；满产物槽、暂停基座不占用分配。已分配因子按每个服务器刻累积，下一件进度和当前产速同步到 UI；暂停保留已获得的分数进度，切换目标清空进度，断网不会用过期额度产出。
- JEI 新增全部 105 条增殖配方，核对触媒 U 查询、产物 R 查询、不消耗触媒提示、产物数量及两种工作站入口。
- 添加农夫乐事 8 个互转组及种子随机池；添加粘液球/岩浆膏互转、24 条原木/木头溯源树苗或菌类、4 条鱼加水桶复活配方。全部 83 条进阶执行校验通过。随机结果在堵塞重试及存档后保持，成功时才扣料。
- 增殖目录为 105 条初级天然材料/19 种触媒。10 个树木系列使用对应树苗或红树胎生苗，下界木材及植物使用对应菌类，竹子使用竹子；紫水晶碎片覆盖石料、常见花与部分沙土，回响碎片覆盖植被、蘑菇及灵魂地形，水生植物使用海洋之心，末地石使用末影珍珠，冰和尖锐滴水石锥保留浮冰/滴水石块。移除船、木门、工具、染料及加工植物触媒；排除木板、砂岩、玻璃等加工目标。审阅依据见 `../growth-recipe-review-1.6.0.md`。
- 基座统一使用水晶本体的 geode 材质和晶体纹素发光。母岩增殖台和触媒基座四角晶芽按 0/90/180/270 度旋转，分别朝向西北/东北/东南/西南；已独立核对实际导出模型的尖端坐标、根部位置和晶体发光。黑金浮雕回折面修正 UV，补齐侧面；末地动态环使用 ring_glow 材质，并在动态渲染中全亮。
