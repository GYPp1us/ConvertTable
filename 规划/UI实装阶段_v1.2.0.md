# UI 与检测实装版 1.2.0

本页优先于此前概念图和 v1.4 UI 草案中的冲突内容。运行目标仍为 Minecraft 26.2 / Fabric；26.3 配方文件只用于提取目标预览分组。

- 猪灵：输入、金粒、输出三槽，没有目标选择和进度条。
- 末地：输入模式、目标搜索/分页、指定输入/同组匹配偏好、燃料槽和未启用的相位储量区域。
- 幽匿：继承末地界面，通过“目标 / 范围”切换右侧面板。范围沿 Z 轴投影到 X–Y 平面，X 向右、Y 向上；Z 方向重叠压为同一格，不展示三维世界模型。
- 容器仅显示连接数量，无输入/输出角色。曼哈顿半径 4，最多 8 个，双箱合并为一个；检测不会打开容器、触发战利品或传输物品。
- 幽匿检测使用六向相邻连接，包含幽匿块、脉络、催发体、两种感测体和尖啸体。脉络按实际附着面检查连接，目前不跨对角位置追踪绕角脉络。范围上限为曼哈顿半径 16 / 1024 节点。
- 每秒同步一次已加载区域的检测结果；达到上限或遇到未加载区域时显示“不完整”，不强制加载区块。
- 投影颜色：青色为连通节点，浅青为上方无碰撞遮挡的幽匿块候选表面，黄色为转换台。表面显示尚未用于实际死亡计数。
- 输入、燃料、模式与目标偏好随方块实体存档，输出槽禁止放入物品。移除方块使用原版容器内容掉落机制。

本阶段没有实装转换配方、扣除燃料、容器批量搬运或生物死亡计数。搜索出的物品仅用于 UI 预览，并不表示转换现已可执行。原有三种转换台本身的合成配方保留。

后续幽匿能量按既定策划使用连通幽匿表面上的生物死亡计数，不消耗玩家经验。收藏和最近目标留待后续。
