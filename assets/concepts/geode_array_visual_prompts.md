# 晶洞阵法讲解图提示词

使用 Codex 内置 image_gen 生成两张像素风立体图；水晶台外形参照 `assets/geode_prototype/geode_three_quarter.png`。下列为最终画面要求的整理版。

## 单方向剖面

Minecraft 风格、横向教学剖面。六个连续格子，从左到右依次为：白色晶洞水晶台、普通紫水晶块、紫水晶母岩、仅供晶芽生长的空气格、方解石、平滑玄武岩。在每格下标出 1–6。晶芽附着在母岩朝空气格的一面；空气格须清楚呈现为空位。整图用于解释单个生长面的摆放顺序。

## 三面立体示例

Minecraft 风格、近俯视等距像素画。以水晶台为西端，向东依次连接普通紫水晶块和一块母岩。从母岩向北、东、南伸出三条正交生长臂；每条臂向外依次是空气中的晶芽、白色方解石、深色平滑玄武岩。西侧被连接块占据。地面有清楚的格线，不加入阵法外的方块，不写文字。
